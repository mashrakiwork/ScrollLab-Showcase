## Why Scroll Lab

A scroll animation usually means a few elements sliding in. These pages go further: the scrollbar directs the whole page, moving the camera, the product and the story together, and it runs smoothly in the browser.

|  |  |
|---|---|
| **3D pages** | Real models rendered frame by frame, with the camera orbiting, diving in and pulling away as you scroll. |
| **Film pages** | Shot-by-shot film scrubbed by the scroll, so one continuous motion plays forwards and backwards under your finger. |
| **Made for 60 fps** | Frames are decoded ahead of the scroll, so the picture keeps up however fast you move. |
